# oneday 时间轴编辑

oneday 把时间轴存为 Obsidian 笔记里的 ` ```timeline ` 代码块。**markdown 源码是唯一事实源**：你只编辑代码块内部，插件会自动重新渲染。**绝不改动代码块以外的正文。**

## 语法

```
date: 2026-08-18        # 可选；缺省取笔记日期
range: 7-23             # 可选；时间轴范围
---
plan 08:00-09:30 math 线代第一章      # plan 前缀 = 规划层（低透明背景）
09:15-12:15 math 李林线代第一章·行列式  # 实际色块：HH:MM-HH:MM <type> [备注]
12:15-13:30 sleep 午休
@21:40 头晕，提前收工                  # @HH:MM = 点批注
```

- 24 小时制，粒度 15 分钟。**跨零点算当日**：早于 range 起点的时间（如 `00:30-01:30`）表示次日凌晨，仍属于这一天。
- 时长不需要写，渲染时自动算。
- 条目按开始时间升序排列。

## 工作流：用户说「我刚花了半小时健身」

1. 获取当前时间（`date "+%H:%M"`）。
2. 算属性：end=当前时间，start=往前推时长；「从 a 到 b」类描述直接用给定时间。
3. 选 type：对照插件设置里的类型表（如 math/micro/english/sleep/meal/fitness/misc），拿不准用 `misc`。
4. 找到目标笔记里的 ` ```timeline ` 块，按时间顺序**插入**一行 `HH:MM-HH:MM type 备注`。
5. 自检：与已有实际色块不重叠；若有冲突，向用户报告而不是覆盖。

## 边界

- 只编辑 timeline 代码块内部；块外正文一个字都不动。
- plan 条目允许重叠；实际条目之间不允许重叠。
- 没有 timeline 块的笔记：先问用户要不要新建一个。
